# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [1.1.0] - 2026-10-25

### Добавлено

- Топ-10 рекордов в JSON с атомарной записью и версией схемы (`snake_game/storage.py`).
- Пауза по `P`; ввод направления игнорируется, пока игра на паузе.
- Отдельная полоса HUD высотой 36 px: счёт, рекорд и индикатор паузы.
- Флаги `--version`, `--scores`, `--seed` и консольная команда `snake-game`.
- Пакет `snake_game` с чистым ядром без pygame (`core.py`).
- Тесты на ядро, хранение рекордов и headless-отрисовку (29 тестов).
- `pyproject.toml`, ruff, mypy strict и CI на Python 3.11 / 3.13.
- `snake-game.spec` для сборки exe через PyInstaller.

### Изменено

- `main.py` стал тонкой точкой входа, логика вынесена в пакет.
- Окно выросло на высоту HUD, игровое поле сдвинуто вниз.

### Исправлено

- Счёт больше не перекрывает змейку и еду.
- Повреждённый файл рекордов не приводит к падению: он откладывается в сторону.
